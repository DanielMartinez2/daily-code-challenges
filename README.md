# Daily Code Challenges

A collection of daily algorithm and problem-solving challenges implemented in **JavaScript** and **Python**.

This repository is part of my ongoing programming practice and focuses on strengthening problem-solving skills, algorithmic thinking, code readability, and familiarity with different programming approaches.

## Languages

* JavaScript
* Python

## Topics Practiced

The challenges cover a variety of programming concepts, including:

* strings;
* arrays and lists;
* loops;
* recursion;
* mathematical problems;
* data manipulation;
* searching and sorting;
* validation;
* conditional logic;
* basic data structures;
* algorithm design.

The topics vary as new challenges are completed.

## Running the Challenges

Each challenge can be executed independently.

### Python

```bash
python Python/file_name.py
```

### JavaScript

Using Node.js:

```bash
node JavaScript/file_name.js
```

## Purpose

The goal of this repository is not to build a single application, but to document continuous practice in programming and problem solving.

Working on small challenges regularly provides an opportunity to:

* practice translating problems into code;
* explore different solution strategies;
* improve algorithmic reasoning;
* compare approaches across programming languages;
* write clearer and more efficient code.

New challenges are added regularly as part of my ongoing learning and programming practice.
